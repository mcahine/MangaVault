# 界面截图说明

> 这些图用于 README 展示，**全部来自一台机器上的真实运行界面**，但库里的内容不是真漫画。

## 内容来源

截图使用的库根是一个**程序生成的虚构夹具**：

- 12 部原创标题的作品（如「星海邮差」「深夜食堂手记」），元数据、章节、页数都是造的；
- 每张「内页」与封面都是用零依赖 PNG 编码器画出来的**抽象分镜占位图**（渐变底 + 2×3 分格 + 高光斑），不临摹、不含任何真实漫画内容；
- 查重台那张里的「查重目录」是同一套夹具的两部换名副本 + 一部新作，用来演示真实候选复核的效果。

这样做是刻意的：仓库是公开的，截图里不该出现任何真实作品或任何 R18 内容。

## 怎么重新生成

用无头 Edge + CDP 截 1440×900 @2x（产出 2880×1800，压成质量 92 的 JPEG）。
关键点：

- 用 `--remote-debugging-port=0` 并读 `DevToolsActivePort` 拿端口，别猜固定端口（会撞车）；
- 阅读器的工具栏与翻页条 2.8 秒后自动隐藏，截图前必须先 `Input.dispatchMouseEvent` 移动鼠标让它们显形；
- 查重台要先进「候选复核」（快速查重跑过才有内容）；
- 必须用隔离的 `MV_DATA_DIR`，绝不能指向真实数据目录。
